# MapLibre Compose

Shared language for maps, location, and heading across the supported platforms.

## Location and heading

**Location measurement**: A timestamped estimate of a geographic position, with
optional motion and accuracy values. _Avoid_: Location reading, location fix

**Heading measurement**: A timestamped estimate of the horizontal direction that
a device faces, relative to a specified north reference. _Avoid_: Heading
reading, heading fix
