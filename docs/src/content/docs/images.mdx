A <Api of="SymbolLayer" /> draws an icon at each feature in its source. Its
`iconImage` parameter takes an <Api of="image" /> expression, which chooses the
icon.

## Draw icons from a Compose painter

Pass any Compose `Painter` to `image()`. You can load one with
`painterResource` or draw your own. This painter draws a badge using your
Material theme's colors and typography:

<Code code={region(images, "badge-painter")} lang="kotlin" title="App.kt" />

Use the painter as an icon on a <Api of="SymbolLayer" />:

<Code code={region(images, "icon-painter")} lang="kotlin" title="App.kt" />

`image()` uses the painter's intrinsic size; pass `size` to set a different
icon size. To color a single-color icon from the layer,
pass `drawAsSdf = true` to `image()` and set the layer's `iconColor`.

The map hides an icon that would overlap another icon or label. Set
`iconAllowOverlap = const(true)` on the layer to draw every icon.

## Place an image on the map

<Api of="rememberImageSource" /> pins one image to the map at four corner
coordinates, and a <Api of="RasterLayer" /> draws it. The image moves and
scales with the map. This example lays a 1660 plan of New Amsterdam over lower
Manhattan:

<Code code={rememberedMapStyle(region(images, "image-source"))} lang="kotlin" title="App.kt" />

The corners do not need to form a rectangle that faces north, so you can
rotate the image to fit the map. To draw pixels that your app creates, pass a
<Api of="PreparedImage" /> instead of a URI.

## Supply a missing image

A layer can ask for an icon that the style does not contain, for example when
your data names an icon for each feature. The map then draws no icon for that
feature. Set <Api of="MapState.missingImageResolver" /> to supply the image
when the map asks for it. This example draws a fallback painter for every
missing icon:

<Code code={region(images, "missing-image")} lang="kotlin" title="App.kt" />

The resolver receives a <Api of="MissingImageRequest" /> with the icon's ID.
Return a <Api of="ResolvedStyleImage" />, or null to leave the icon empty.

To add or replace an image under a fixed ID from code, call
<Api of="StyleImages.set" /> on `mapState.style.images`.
