## Prepared images

`PreparedImage.fromBitmap` copies a bitmap's pixels into the form the map
uploads. It runs on the calling thread and takes longer for larger images, so
call it off the main thread for large images. The result can be reused across
maps, loaded styles, and image IDs.

An image source and <Api of="MutableImageSourceHandle.setImage" /> take a
`PreparedImage`. A style image takes a <Api of="ResolvedStyleImage" />: build
one from a `PreparedImage` and the style-image options, or render a painter
with `ResolvedStyleImage.fromPainter`. Submit it with
`state.style.images.set(id, image)`.

`set`, `setAll`, and `remove` enqueue commands without waiting for the map. A
replacement keeps the previous image until it succeeds; an engine rejection is
logged. Looking up an image with `state.style.images[id]` suspends until the
commands enqueued before it have run, so code that needs an image in place
awaits its lookup. A finished command does not mean the map has rendered a
frame.
