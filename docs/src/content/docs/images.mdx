A `SymbolLayer` draws an icon at each feature in its source. The `image()`
expression supplies the icon, from a Compose painter, an `ImageBitmap`, or the
base style's sprite.

## Draw icons from a Compose painter

Pass a painter to `image()`. The library rasterizes it and registers it with
the style. This works with `painterResource`, vector drawables, and any other
painter:
