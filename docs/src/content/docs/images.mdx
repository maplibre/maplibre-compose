## Prepared images

`PreparedImage.fromBitmap` copies a bitmap's pixels once, on the calling
thread, into the form the map uploads. The result can be reused across maps,
loaded styles, and image IDs. An image source and
<Api of="MutableImageSourceHandle.setImage" /> take a `PreparedImage`. A style
image takes a <Api of="ResolvedStyleImage" />: either
`ResolvedStyleImage(image, sdf, stretch)` or `ResolvedStyleImage.fromPainter`.
Submit it with `state.style.images.set(id, image)`.

`set`, `setAll`, and `remove` enqueue commands without waiting for the map. A
replacement keeps the previous image until it succeeds; an engine rejection is
logged. Looking up an image with `state.style.images[id]` suspends until the
commands enqueued before it have run, so code that needs an image in place
awaits its lookup. A finished command does not mean the map has rendered a
frame.
