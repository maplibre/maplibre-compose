A style is a JSON document that tells the map what to draw. It lists the data
sources, such as vector tiles, and the layers that draw that data: roads,
water, buildings, labels.

## Choose a style

You usually get a style from a map tile provider, which serves the style and
the tiles it uses. The [awesome-maplibre][awesome-maplibre] list names free and
commercial providers. The examples in this documentation use
[OpenFreeMap][openfreemap], which needs no account, and
[Protomaps][protomaps], which needs an API key.

To design your own style, edit one in [Maputnik][maputnik], a visual style
editor.
