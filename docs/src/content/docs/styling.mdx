Every map requires a style: a JSON document that describes the data the map
shows and how the map draws it. Tile providers usually publish styles designed
for their data and serve them at a URI. You can also create your own styles
with [Maputnik][maputnik], a visual style editor for MapLibre styles.

Free and commercial tile providers are listed in the
[awesome-maplibre][awesome-maplibre] repository. This documentation uses
[OpenFreeMap][openfreemap] and [Protomaps][protomaps].

Omitted overrides keep the base style's values. Clearing an override restores the
current base style's value. Light is supported on every platform. Sky, projection,
and 3D terrain overrides are available in the browser.

## Show 3D terrain in the browser

Terrain draws the map on elevation data from a raster DEM source. Pass the source
to <Api of="WebTerrain" />; the map installs it even when no layer uses it.
`exaggeration` scales the elevation:

<Code code={region(browserStyling, "terrain")} lang="kotlin" title="App.kt" />

To use a raster DEM source already in the base style, pass its ID to `WebTerrain`.
Use separate DEM sources for terrain and hillshade or color relief layers, as
MapLibre recommends for rendering quality.

`removeSky()` and `removeTerrain()` in the overrides builder remove those objects,
including ones in the base style. Setting `sky` or `terrain` to null instead stops
overriding that object and restores the base style's value.
