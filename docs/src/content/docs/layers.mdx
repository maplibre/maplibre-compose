The base style defines the map's content. To show your own data on top of it,
declare sources and layers in the trailing <Api of="rememberMapState" /> block,
then pass that state to <Api of="MaplibreMap" />. A source holds the data, and a
layer draws data from a source.

## Time a property change

When a paint property changes, the map animates it over the style's global

<Code code={rememberedMapStyle(region(layers, "transitions"))} lang="kotlin" title="App.kt" />

<Api of="StyleTransition" /> reads and sets.

## Define a layer type

Plugin libraries can provide typed composables using <Api of="Layer" />. Built-in
layers use the same property builder and lifecycle machinery:

<Code code={region(layers, "plugin-layer")} lang="kotlin" title="PluginMeshLayer.kt" />

The builder accepts named root, layout, and paint properties as expressions or
JSON values. Expressions can contain managed painters and bitmaps, just as they
can in built-in layers. Use `paintTransition` for transition timing and
<Api of="LayerExpressionContext" /> when a property needs text-unit conversion.

The properties block is a regular Kotlin builder. Call composable helpers
before the block; use `LayerProperties` receiver extensions to share groups of
properties.

Each invocation describes the complete layer. Properties omitted on recomposition are
removed. Paint, layout, filter, and zoom changes update the layer; changes to
its type, source, source-layer, or other root fields replace it. The surrounding
`Anchor` and the layer's interaction parameters work as they do for built-in
layers.

The generic API passes property names to the engine without Compose's
style-spec filtering. The engine must support the layer type and properties.
Register Native plugins through the FFI before declaring their layers; this API
does not load plugins or provide equivalent implementations in the browser.

## Declare a JSON layer

Use <Api of="RawLayer" /> when you already have a layer's style JSON:

<Code code={region(layers, "raw-layer")} lang="kotlin" title="App.kt" />

Raw JSON preserves unknown fields, explicit nulls, and transition timing. It does
not perform expression conversion or apply the system animation-duration scale.
Image names in JSON must already exist in the style. Use the builder above for
managed images and Compose-aware transition timing.

Both APIs accept a managed `Source`. Without one, a JSON `source` property
references an existing style source. The explicit layer ID and managed source
must agree with any IDs in the JSON. Composition retains managed sources while
layers use them and removes the declared layers when they leave composition.
