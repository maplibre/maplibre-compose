To draw your own data, you add a source and at least one layer. A source holds
data, such as points, lines, or shapes. A layer draws the data from one source
in one way, for example as lines or circles. Declare both in the block that you
pass to <Api of="rememberMapState" />.

Layers draw in the order you declare them, so the wide white line goes first
and the blue line draws on top of it. Each layer needs an ID that no other
layer in the map uses.

<Api of="GeoJsonData" /> also takes a GeoJSON string or a GeoJSON object that
you build in Kotlin. When the data changes, pass a new value, and the map
redraws the layers. To group many nearby points, see
[Cluster points](/maplibre-compose/clustering/). To respond when the user taps
a feature, see
[Handle gestures and clicks](/maplibre-compose/interaction/#respond-to-clicks-on-a-layer).

Other sources load tiles from a server:
<Api of="rememberVectorTileSource" /> for vector tiles and
<Api of="rememberRasterTileSource" /> for image tiles.
[Show 3D buildings and relief](/maplibre-compose/terrain/) uses elevation
tiles, and
[Add images and icons](/maplibre-compose/images/) places a single image.

## Draw under the labels

Your layers draw above the whole base style, so a line covers street names and
place names. <Api of="Anchor.Companion.Below" display="Anchor.Below" /> puts
layers lower in the stack. This example draws `trail` under all of the base
style's labels and icons, whatever the style names those layers:

<Code code={rememberedMapStyle(region(layers, "anchors"))} lang="kotlin" title="App.kt" />

The lambda receives a <Api of="LayerSummary" /> for each base style layer.
Layers with the type `symbol` draw text and icons. To place your layers next to
one layer that you know, pass its ID instead, such as
`Anchor.Above("road_motorway") { ... }`. `Anchor.Bottom` draws your layers
under the whole base style.

## Animate property changes

When a property such as a color changes, the map fades from the old value to
the new one. Pass <Api of="TransitionOptions" /> to set how long that takes for
one property. Here the `trail` line turns red over half a second when
`selected` becomes true:

<Code code={rememberedMapStyle(region(layers, "transitions"))} lang="kotlin" title="App.kt" />

Each property that can fade has a parameter that ends in `Transition`, such as
`colorTransition` for `color`.
