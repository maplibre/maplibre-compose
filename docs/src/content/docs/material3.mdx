The controls that the base library draws take their colors from a fixed palette
that reads over any basemap, because Compose Foundation carries no theme. This
module replaces them with versions that read your Material 3 color scheme and
typography, and adds a compass and a scale bar.

To get started, add the dependency to your project:

```toml title="libs.versions.toml"
[libraries]
maplibre-composeMaterial3 = { module = "org.maplibre.compose:maplibre-compose-material3", version = "{{release}}" }
```

```kotlin title="build.gradle.kts"
commonMain.dependencies {
  implementation(libs.maplibre.composeMaterial3)
}
```

Then build a `MapOverlay` out of them. See
[Map controls](/maplibre-compose/controls/) for how the overlay lays out and how
to keep it clear of other UI.
