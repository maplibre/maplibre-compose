An offline pack holds the resources needed to show a region without a network:
map tiles, the style, and other assets. The `OfflineManager` creates, tracks,
and deletes packs.

<Aside type="note">
  Offline packs are available on Android, iOS, and Desktop. The browser
  platform does not support them.
</Aside>

Get the manager inside a composition:

<Code code={region(offline, "manager")} lang="kotlin" />

## Download a region

A pack is defined by a style URL, a bounding box, and a zoom range. `create`
registers the pack in a paused state; call `resume` to start the download:

<Code code={region(offline, "create")} lang="kotlin" />

The `metadata` bytes are yours to define. Use them to identify the pack later,
for example with a display name.

`OfflinePackDefinition.Shape` downloads the region that covers a GeoJSON
geometry instead of a bounding box.

## Track download progress

`OfflineManager.packs` and `OfflinePack.downloadProgress` are backed by
Compose state, so a composition that reads them recomposes as the download
proceeds:

<Code code={region(offline, "progress")} lang="kotlin" />

`pause` and `resume` switch a pack between the `Paused` and `Downloading`
states. `invalidate` re-checks a pack's tiles against the server and updates
the ones that changed.

## Delete a pack

`delete` unregisters the pack and frees the resources that no remaining pack
requires:

<Code code={region(offline, "delete")} lang="kotlin" />

Once a pack is downloaded, the map uses its resources automatically when the
device has no network. No map configuration is required.
