An offline pack stores the style, tiles, fonts, and icons for one area, so the
map can show that area without a network connection. Use packs when people
need the map in places with no signal, such as on a hike or a flight.

<Aside type="note">
  Offline packs work on Android, iOS, macOS, and desktop (JVM). The browser has
  no offline storage, so call this API from those platforms' source sets.
</Aside>

## Download a region

<Api of="OfflineStorage.create" /> saves a new pack, and
<Api of="OfflineStorage.resume" /> starts its download:

<Code code={region(offline, "create")} lang="kotlin" title="App.kt" />

The pack is defined by:

- `styleUrl`: the style that the map uses. Use the same URL in the map, because
  MapLibre finds downloaded resources by their URL.
- `bounds`: the area to download. To download the area of a GeoJSON shape, such
  as a hiking route, use <Api of="OfflinePackDefinition.Shape" /> instead.
- `minZoom` and `maxZoom`: the zoom levels to download. Each extra zoom level
  needs about four times as many tiles as the one before, so keep `maxZoom` as
  low as your use case allows.
- `pixelRatio`: the screen density, so the pack has tiles for this screen.

`metadata` holds any bytes you want to keep with the pack. The example stores a
name to show in a list.

The button stays disabled while the storage opens its database.

## List downloaded packs

<Api of="OfflineStorageState.Ready" /> lists every pack in the database,
including packs from earlier app launches. The `maplibre-compose-material3`
module has <Api of="OfflinePackListItem" />, which shows a pack's progress and
has buttons to pause, resume, update, and delete it:

<Code code={region(offline, "list")} lang="kotlin" title="App.kt" />

A download stops when the app closes. On the next launch, an incomplete pack is
paused until you call `resume` again. `OfflinePackListItem` shows a resume
button for it.

## Show download progress

To build your own UI, collect <Api of="OfflinePack.downloadProgress" />. It
updates as resources download:

<Code code={region(offline, "progress")} lang="kotlin" title="PackProgress.kt" />

<Api of="DownloadProgress.Healthy" /> counts downloaded and required resources
and tells you whether the pack is downloading, paused, or complete.
<Api of="DownloadProgress.Error" /> and
<Api of="DownloadProgress.TileLimitExceeded" /> report a problem.

## Show the downloaded area on a map

You do not need to configure the map. A map from the same runtime uses the
pack's resources, so the downloaded area shows when the device has no network.
