You need a Compose Multiplatform project. To create one, follow
[the JetBrains guide][compose-guide] or run `kotlin init compose-multiplatform`.

## Add the library

The library is on [Maven Central][maven]. The latest release is
**v{versions.release}**. Add it to your version catalog:

```toml title="libs.versions.toml"
[libraries]
maplibre-compose = { module = "org.maplibre.compose:maplibre-compose", version = "{{release}}" }
```

Then add it to the shared source set:

<Tabs syncKey="build-system">
  <TabItem label="Gradle" icon="seti:gradle">
    ```kotlin title="build.gradle.kts"
    commonMain.dependencies {
      implementation(libs.maplibre.compose)
    }
    ```
  </TabItem>

  <TabItem label="Kotlin Toolchain" icon="seti:kotlin">
    ```yaml title="shared/module.yaml"
    dependencies:
      - $libs.maplibre.compose
    ```
  </TabItem>
</Tabs>

## Set up each target

Follow the steps for each target your app has. Android and desktop also need a
runtime artifact, which contains the native map engine for one graphics API. Use
the same version for the library and the runtime. The steps below pick one
runtime per target; [Platform setup](/maplibre-compose/platform-setup/) lists
the others and explains how to choose.

### Android

Add the Vulkan runtime to the Android app:

<Tabs syncKey="build-system">
  <TabItem label="Gradle" icon="seti:gradle">
    ```kotlin title="build.gradle.kts"
    androidMain.dependencies {
      runtimeOnly("org.maplibre.compose:maplibre-compose-runtime-vulkan-android:{{release}}")
    }
    ```
  </TabItem>

  <TabItem label="Kotlin Toolchain" icon="seti:kotlin">
    ```yaml title="android-app/module.yaml"
    dependencies:
      - //shared
      - org.maplibre.compose:maplibre-compose-runtime-vulkan-android:{{release}}:
          scope: runtime-only
    ```
  </TabItem>
</Tabs>

### iOS

iOS needs no runtime artifact. The app must target iOS 15.5 or later.

Add these lines to **Other Linker Flags** in your iOS app target's build
settings:

```text
-l"c++"
-lz
-framework CoreFoundation
-framework CoreGraphics
-framework CoreText
-framework Foundation
-framework ImageIO
-framework Metal
-framework QuartzCore
```

### Desktop (JVM)

Desktop apps run on Java 25 or later. These steps use a Compose Desktop window,
which runs on AWT. [Platform setup](/maplibre-compose/platform-setup/#window-hosts)
covers other windows, including Nucleus, which we recommend.

Add the runtime for each operating system and CPU you ship, and
`kotlinx-coroutines-swing`, which supplies the main thread that maps deliver
their events on. This example is for Linux on x64:

<Tabs syncKey="build-system">
  <TabItem label="Gradle" icon="seti:gradle">
    ```kotlin title="build.gradle.kts"
    jvmMain.dependencies {
      implementation("org.jetbrains.kotlinx:kotlinx-coroutines-swing:{{coroutines}}")
      runtimeOnly("org.maplibre.compose:maplibre-compose-runtime-vulkan-linux-x64:{{release}}")
    }
    ```
  </TabItem>

  <TabItem label="Kotlin Toolchain" icon="seti:kotlin">
    ```yaml title="desktop-app/module.yaml"
    dependencies:
      - //shared
      - org.jetbrains.kotlinx:kotlinx-coroutines-swing:{{coroutines}}
      - org.maplibre.compose:maplibre-compose-runtime-vulkan-linux-x64:{{release}}:
          scope: runtime-only
    ```
  </TabItem>
</Tabs>

The map engine calls native code through Java's foreign function API, so the
JVM must start with `--enable-native-access=ALL-UNNAMED`:

<Tabs syncKey="build-system">
  <TabItem label="Gradle" icon="seti:gradle">
    ```kotlin title="build.gradle.kts"
    compose.desktop {
      application {
        jvmArgs += "--enable-native-access=ALL-UNNAMED"
      }
    }
    ```
  </TabItem>

  <TabItem label="Kotlin Toolchain" icon="seti:kotlin">
    ```shell
    kotlin run --module desktop-app --jvm-args="--enable-native-access=ALL-UNNAMED"
    ```

    Pass the same flag when you start a packaged JAR:
    `java --enable-native-access=ALL-UNNAMED -jar desktop-app-jvm-executable.jar`.
  </TabItem>
</Tabs>

## Display a map

Add a map to your shared UI:

<Code code={region(gettingStarted, "first-map")} lang="kotlin" title="MyMap.kt" />

<Api of="rememberMapState" /> creates the map's state. `baseStyle` loads a
style from a URL. The style decides what the map shows and how it looks. This
example uses the free [OpenFreeMap][openfreemap] Liberty style. If you leave out
`baseStyle`, the map shows the [MapLibre demo style][demotiles], which has
little detail. `initialCameraPosition` is where the map opens: here, downtown
Portland at zoom 13.

<Api of="MaplibreMap" /> fills all the space its parent gives it. Users can
pan, zoom, rotate, and tilt the map with touch gestures or a mouse.

Next, [choose a style](/maplibre-compose/styling/) or
[move the camera](/maplibre-compose/camera/).
