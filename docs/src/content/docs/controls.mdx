`MaplibreMap` draws controls on top of the map. The `overlay` parameter sets
which ones. The default is a scale bar and a compass along the top edge, and
the MapLibre logo and an attribution button along the bottom edge. The scale
bar and the compass appear only while they are relevant.

<Code code={region(controls, "default")} lang="kotlin" title="App.kt" />

<Aside type="caution">
  Most tile sources require attribution. `MapOverlay.Default` reads it from
  `StyleState.attributions()`. If you replace the overlay, show that attribution
  yourself.
</Aside>

## Choose an overlay

`MapOverlay.None` draws no controls. Use it when your app shows the attribution
somewhere else, such as an about screen.

A `MapOverlay` block draws the controls you list in it. `Modifier.align`
positions a control against an inset edge of the map.

1. The block can read the map's `cameraState` and `styleState`, so a control

## Theme the controls with Material 3

The base library draws controls with a fixed palette that reads over any
basemap. The `maplibre-compose-material3` module draws the same controls with
your Material 3 color scheme and typography. Add the dependency:

```toml title="libs.versions.toml"
[libraries]
maplibre-composeMaterial3 = { module = "org.maplibre.compose:maplibre-compose-material3", version = "{{release}}" }
```

```kotlin title="build.gradle.kts"
commonMain.dependencies {
  implementation(libs.maplibre.composeMaterial3)
}
```

`MapOverlay.Material3` draws the same controls as `MapOverlay.Default` in the
same places, so switching to it is one parameter:

## Inset overlays and the camera

Use `contentWindowInsets` to inset overlay controls. Use `cameraPadding` to
shift the camera center. They can use the same values or vary independently.

<Code code={region(controls, "insets")} lang="kotlin" title="App.kt" />

1. `union` takes the larger inset on each edge.

Padding on a bounding-box camera move adds to `cameraPadding` for that fit.

## Pin Compose UI to a location

`Modifier.placedAt` puts a child on a geographic position. Keep the default
controls with `include`, then add the child in the same overlay. A pan, a zoom,
or a window resize moves the child with the map.

<Code code={region(controls, "placedAt")} lang="kotlin" title="App.kt" />

1. `Alignment.BottomCenter` sits the bottom edge of the chip on the point.
   Padding lifts the chip above the feature.

## Point at an off-screen location

`Modifier.placedTowards` puts a child on the edge of an ellipse inscribed in
the unobstructed map region, on the line towards a geographic position. The
child appears only while the position projects outside of that ellipse. A
position near a corner of the map region can be visible and still lie outside
the ellipse.

<Code code={region(controls, "placedTowards")} lang="kotlin" title="App.kt" />

1. The state carries the placement that the overlay computed.
2. `angleDegrees` is the direction of the target, clockwise from screen-up.

`PointerPinButton` from the Material 3 module is a styled consumer of this
modifier: an elevated button in the shape of a pin that points at the target.
