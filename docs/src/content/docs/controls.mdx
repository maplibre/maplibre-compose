<Api of="MaplibreMap" /> draws Compose UI on top of the map in its trailing
`overlay` block. Without a block, it draws <Api of="MapOverlay.Default" />: a
scale bar and a compass along the top edge, and the MapLibre logo and an
attribution button along the bottom edge. The scale bar appears for a moment
when the zoom changes. The compass appears while the map is rotated or tilted.

<Code code={region(controls, "default")} lang="kotlin" title="App.kt" />

The attribution button shows the attribution text of the sources in the style.

<Aside type="caution">
  Most tile providers require you to show their attribution. If you remove the
  attribution button, show the attribution somewhere else in your app.
</Aside>

## Choose a preset

<Api of="include" /> draws a preset inside the overlay block.
<Api of="MapOverlay.Full" /> adds zoom buttons to the default controls, which
helps users with a mouse. <Api of="MapOverlay.AttributionOnly" /> keeps only
the logo and the attribution button.

<Code code={region(controls, "preset")} lang="kotlin" title="App.kt" />

An empty block draws nothing. Use it when your app shows the attribution
somewhere else. Call <Api of="attributions" /> on `mapState.style` to get the
attribution text of the style's sources, and draw it with

## Add your own controls

The overlay block lays out its children like a `Box` that covers the map. This
example puts the controls in a `Box` with `safeDrawingPadding()`, so they stay
clear of the system bars, and places each one with `Modifier.align`.

<Code code={region(controls, "custom")} lang="kotlin" title="App.kt" />

The library's controls, such as
<Api of="org.maplibre.compose.overlay.ZoomButtons" /> and
<Api of="org.maplibre.compose.overlay.CompassButton" />, are composables you can
place the same way.

## Use Material 3 colors

The base controls use fixed colors that are readable on light and dark maps.
The `maplibre-compose-material3` module draws the same controls with the colors
and typography of your Material 3 theme. Add the dependency:

```toml title="libs.versions.toml"
[libraries]
maplibre-composeMaterial3 = { module = "org.maplibre.compose:maplibre-compose-material3", version = "{{release}}" }
```

```kotlin title="build.gradle.kts"
commonMain.dependencies {
  implementation(libs.maplibre.composeMaterial3)
}
```

Then include <Api of="Material3" display="MapOverlay.Material3" />. It places
the same controls as <Api of="MapOverlay.Default" />.
`MapOverlay.Material3Full` and `MapOverlay.Material3AttributionOnly` are the
Material 3 versions of `MapOverlay.Full` and `MapOverlay.AttributionOnly`.

## Read the map in a control

A control can read the map it is drawn on through
<Api of="LocalMapState" />. You do not need to pass the map state to it. This
label shows the current zoom level and updates as the user zooms:

<Code code={region(controls, "map-context")} lang="kotlin" title="ZoomLabel.kt" />

<Api of="LocalMapState" /> is null outside a map. <Api of="LocalViewport" />
gives the camera, size, and visible area of the last frame the map drew.

## Keep controls clear of your UI

When your app draws UI over part of the map, such as a bottom panel, pass that
area to `viewportInsets`. The default controls then stay above the panel, and
camera moves center their target in the part of the map the user can see.

<Code code={region(controls, "insets")} lang="kotlin" title="App.kt" />

Your own controls can read the same insets from
<Api of="LocalViewportInsets" /> and apply them as padding.

## Pin UI to a location

<Api of="MapOverlayScope.placedAt" /> puts a composable on a geographic
position. The composable moves with the map when the user pans or zooms. Use it
for a label or a button that belongs to a place. Apply it to a direct child of
the overlay block.

<Code code={region(controls, "placedAt")} lang="kotlin" title="App.kt" />

The `alignment` chooses which point of the composable sits on the position.
`Alignment.BottomCenter` puts the bottom of the label on the position, and the
bottom padding lifts it a little above.

## Point to an off-screen location

<Api of="org.maplibre.compose.overlay.PointerPinButton" /> shows a pin at the
edge of the map that points toward a position outside the view. The pin moves
along an oval that fills its layout, and it hides while the position is inside
that oval. In this example, a tap moves the camera to the position.

<Code code={region(controls, "placedTowards")} lang="kotlin" title="App.kt" />

<Api of="GeographicLayout" /> sets the area that the pin moves around in. Here
the padding keeps the pin away from the system bars and the edge of the map.

To draw your own indicator, use <Api of="MapOverlayScope.placedTowards" /> with
<Api of="rememberPlacedTowardsState" />. The state's
<Api of="PlacedTowardsState.angleDegrees" display="angleDegrees" /> tells you
which way to rotate it.
