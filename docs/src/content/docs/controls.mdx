A map draws a set of controls on top of itself, and the `overlay` parameter
decides which ones. The default draws the MapLibre logo and an attribution
button along the bottom edge.

## Choose your controls

`MapOverlay.None` draws the map alone, for an app that renders attribution
somewhere else, such as an about screen.

<Code code={region(controls, "disabled")} lang="kotlin" title="App.kt" />

To arrange the controls yourself, build a `MapOverlay`. Its content lays out in
a box that covers the unobstructed region of the map, so `Modifier.align` puts a
control against an edge. The scope carries the map's camera and style state.

<Code code={region(controls, "custom")} lang="kotlin" title="App.kt" />

1. `cameraState` and `styleState` come from the overlay scope, so a control that
   is part of an overlay takes no state arguments.

The [Material 3 extensions](/maplibre-compose/material3/) provide themed
versions of these controls, along with a compass and a scale bar.

## Keep controls clear of other UI

The map fills its layout, so a bottom sheet or a system bar can cover part of
it. `contentWindowInsets` names the region that other UI covers, and the overlay
lays its controls out inside what is left.

The default, `WindowInsets.safeDrawing`, subtracts whatever an ancestor has
already consumed. A map inside a scaffold that applies its own insets reads
zero, and a full-bleed map reads the system bars. Add to it when something else
covers the map.

<Code code={region(controls, "insets")} lang="kotlin" title="App.kt" />

1. `union` keeps the larger inset per edge, so the sheet and the system bars
   both stay clear.

The camera reads its own padding, which shifts the point that the map centers
and rotates around. See
[`CameraPosition.padding`](/maplibre-compose/api/lib/maplibre-compose/org.maplibre.compose.camera/-camera-position/padding.html).
