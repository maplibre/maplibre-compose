MapLibre downloads the style, tiles, fonts, and icons from URLs in the style.
You can change these requests from Kotlin code. Do this when:

- your tile server needs an API key or an `Authorization` header,
- requests must go to a different server than the URLs in the style, or
- the app has tiles or fonts in its resources, in a database, or in a file
  that MapLibre cannot read directly.

A <Api of="MapRequestInterceptor" /> changes the URL or headers of a request
before MapLibre sends it. A <Api of="MapResourceProvider" /> returns the data
for a request from your code, so MapLibre sends no request. Both work on every
platform, and they also apply to snapshots and offline downloads.

update the value that the interceptor reads.
