<Api of="MaplibreMap" /> draws a map inside Compose UI. Some screens are drawn
by another UI framework: an Android Auto car screen, a CarPlay screen, a UIKit
or SwiftUI view, or a web page built with Compose HTML, Kobweb, or React. To
show a map there, use a presentation. It draws the map into the surface, view,
or HTML element that the other framework gives you.

You still write the map's sources, layers, and camera code in Kotlin. Create the
<Api of="MapState" /> with <Api of="MapRuntime.createMapState" />, which takes
the same base style and content block as `rememberMapState`, and close the
state when you no longer need the map.

A presentation draws only the map. It has no gestures, buttons, or attribution:

- Pass gestures from your framework to <Api of="MapState.panBy" />,
  <Api of="MapState.scaleBy" />, <Api of="MapState.fling" />, and
  <Api of="MapState.click" />.
- Show the data sources' attribution in your own UI.
  <Api of="attributions" display="state.style.attributions()" /> returns the
  attribution texts as a list of HTML strings.

## Android

`width` and `height` are in physical pixels, and `density` is physical pixels
per dp. The map stops drawing while `lifecycle` is below `STARTED`. Pass the

The [Android Auto demo](https://github.com/maplibre/maplibre-compose/blob/main/demo-app/android-auto/src/main/kotlin/org/maplibre/compose/demoapp/auto/CarMapSurface.kt)
connects these calls to the car app library's `SurfaceCallback`, including
scroll and zoom gestures.

## iOS

<Api of="AppleMapPresentation" /> draws the map, and
<Api of="MaplibreMapView" /> is a UIKit view that shows it:

<Code code={region(apple, "apple-view")} lang="kotlin" title="UiKitMapHost.kt" />

Add `view` to a UIKit view hierarchy or a CarPlay window, or return it from
`makeUIView` in a SwiftUI `UIViewRepresentable`. Set `isActive` from the scene
that shows the map, so the map stops drawing while that scene is in the
background. A CarPlay screen has its own scene, separate from the phone's.

The [CarPlay demo](https://github.com/maplibre/maplibre-compose/blob/main/demo-app/ios/iosApp/CarPlaySceneDelegate.swift)
creates a [Kotlin host](https://github.com/maplibre/maplibre-compose/blob/main/demo-app/common/src/iosMain/kotlin/org/maplibre/compose/demoapp/car/CarPlayMapHost.kt)
like this one from Swift. If you manage your own `CAMetalLayer`, use
<Api of="AppleMapPresentation.attachLayer" /> instead of `MaplibreMapView`.
