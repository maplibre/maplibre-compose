Layer properties in MapLibre are not plain values. Each property takes an
expression: a formula that the map evaluates while it renders, per feature and
per zoom level. The [MapLibre Style Specification][spec-expressions] defines
expressions as JSON arrays. MapLibre Compose provides a Kotlin DSL that builds
them with type checking, in `org.maplibre.compose.expressions.dsl`.

The DSL uses Compose types where they fit: `Dp` for sizes, `Color` for colors,
and `DpOffset` for offsets.

## Kotlin runs before the map, expressions run inside it

Code outside an expression runs once, at composition time, on the device's
CPU. The expression itself runs inside the map renderer, per feature. A Kotlin
`if` selects which expression to build; an expression `switch` selects a value
per feature. Use ordinary Kotlin for decisions that depend on app state, and
expressions for decisions that depend on feature data or zoom.

The full set of expression functions is in the
[API reference](/maplibre-compose/api/) under
`org.maplibre.compose.expressions.dsl`.
